# Screenora Responsive Viewer

Uma extensão para o Google Chrome que permite visualizar qualquer site dentro de um iframe no **Screenora**, removendo restrições de segurança como `X-Frame-Options` e `Content-Security-Policy` (CSP).

## 🚀 Funcionalidades

- **Remoção de X-Frame-Options:** Permite que sites que normalmente bloqueiam exibição em iframes possam ser carregados.
- **Remoção de CSP (Content Security Policy):** Desabilita restrições que impedem o carregamento de recursos em domínios diferentes.
- **Focado no Screenora:** Desenvolvido especificamente para auxiliar na visualização responsiva de projetos no aplicativo Screenora.

## 🛠️ Como Instalar (Modo Desenvolvedor)

Como esta extensão está disponível em código aberto, você pode instalá-la manualmente no seu navegador Chrome:

1. Faça o download ou clone este repositório.
2. Abra o Google Chrome.
3. Acesse a página de extensões digitando `chrome://extensions/` na barra de endereços (ou vá em Menu > Mais ferramentas > Extensões).
4. No canto superior direito, ative a opção **"Modo do desenvolvedor"** (Developer mode).
5. No canto superior esquerdo, clique no botão **"Carregar sem compactação"** (Load unpacked).
6. Selecione a pasta onde os arquivos desta extensão estão salvos (a pasta `extension Screenora`).
7. Pronto! A extensão estará ativa e pronta para uso.
